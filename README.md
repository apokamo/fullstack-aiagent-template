# fullstack-aiagent-template

FastAPIとNext.jsで作る、ストリーミング対応のAIエージェントアプリケーションのテンプレートです。
toolの実行、書き込み前の承認（HITL）、会話の記録、決定的なテストとevalの仕組みを持ちます。
同梱のサンプルエージェントは、自分のエージェントへ置き換える前提の最小の例です。
