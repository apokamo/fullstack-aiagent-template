# Repository instructions

Read and follow the documents below for the work you are doing.

## Required reading before changes

- Before changing code, read the [development workflow](docs/dev/development-workflow.md)
  and the applicable backend or frontend references below.
- Before changing documentation or agent instructions, read the
  [documentation rules](docs/dev/docs-workflow.md).
